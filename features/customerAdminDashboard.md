# Customer Internal Managment Dashboard
## Feature Summary 
This control panel and dashboard allows the admin(s) to update and manage basic aspects of their team.  This only visable to admins. 

### Story  
As a customer admin, I want to be able to view and edit basic elements of my team so I can manage my team's workflow more quickly.
The controls are as follows:
- Assign which suborginzation the account belongs to.
    - Assign a FSO to an orginization/suborganization
- reassign user roles
- view all team members and search with a search bar.
