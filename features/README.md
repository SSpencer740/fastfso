# Features

This directory contains feature specs, design docs, and task descriptions for fastFSO.

## Workflow

1. Create a branch for your feature spec
2. Add a markdown file describing the feature (requirements, design, acceptance criteria)
3. Open a PR for review and discussion
4. Merge when approved — the feature is now part of the backlog

## File Naming

Use kebab-case: `user-authentication.md`, `document-upload.md`, etc.
