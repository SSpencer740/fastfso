# Main list of tasks for others in fastFSO
## Feature Summary
This view is for Non IC roles to check task progress of others in fastFSO.

## Common
This is a view for every non IC user to see a view of the tasks in fastFSO for users in their permission boundry.  This is a read only view intended for checking status.  IC users will not have this tab available to select in the side navigation menu.  Users must be able to perform a search and be able to filter by: suborginization, group, name, task type, and completion status.  
 
### Ability to create 
FSOs and Admins can create tasks within the task admin panel.  They can bulk assign to specific people, by group, sub-org, or to everyone in their scope.  They can also create templates to reuse at a later date.  They can also assign items to be assigned on a future date or make the task recurring.
