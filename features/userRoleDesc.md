# Descriptions of user roles

| role | desc |
| --- | --- |
| Administrator | Can read/write all the information within the tenancy. |
| Read Only FSO | This role can only view the users assigned to their suborganization(s). |
| FSO | This role has read/write permissions for all the users assigned to their suborganization(s). |
| Individual Contributor | This role can only read/write their records. |

Each user will also have their internal position indicated from the following options (individual contributor, management, contractor)
