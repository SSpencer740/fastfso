# Customer Internal Managment Dashboard
## Feature Summary 
Here users can manage their personal settings

## Settings
- Reset password
- Email notification frequency.  Users can choose between the following: 
    - notified of every task that is created for the user
    - Daily summary:  If a user has one or more task created for them in that 24 hour period, they get an email with the number of tasks they have to process.  If they have no tasks created in that 24 hour period, they receive no email.
