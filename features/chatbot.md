# fsoBOT AI Powered Chatbot
## Feature Summary
This AI powered chatbot is a pop up that can be accessed from anywhere in fastFSO. The fsoBOT button should always be accessable on the screen.

- The bot is optimized to answer questions as a facilities security officer might. 
- The bot can also answer questions about user data
    - Note: the bot should only return data for the role assigned.  Eg. if the user type is an Individual Contributor, only data about that user is available.  If the user role is FSO, the bot will have access to all the data of every user under that fso.
