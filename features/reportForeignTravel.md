# Reporting Unclassified Foreign Travel 
## Feature Summary
This section helps users create and manage foreign travel reports. 

## Common
Upon reaching this page, all users will see a list of their reported foreign travel in a table view.  This will display the trip name, trip dates, and whether it is upcoming or completed. Users can filter and search on these criteria. 
Users will click on the button marked "report travel" to open a popup window to fill in the details of their trip.  There will also be a file upload button for itenerary documents.  Each trip report can contain multiple sub trips.  A sub trip is defined as a visit to a different country.  When the user selects report travel, they are first prompted to imput the trip name and select if the trip consists of a visit to multiple countries.  If not, they will be presented with the input fields.  If so, they must list each country they plan on attending.  In the popup, there will be a page for each country containing the input fields.  The user can use arrows to navigate between the popup pages.   

Upon submitting or changing a reported trip, the assigned FSO has an action item created for them with a due date five business days from the day of reporting.

## Non - IC Admin Panel
Non-IC users will also have the ability to view all reported travel in their purview and filter by suborganization.  FSOs and Admins can mark the trip as approved or denied upon their review and submission in DISS. 

## Debrief
Upon returning from the trip (defined as the end date of their trip reported in fastFSO), the reporter has an action item created for them called Post-Travel Debrief.  The task will be to complete a form with the following questions where they can select yes or no.  If yes is selected, there will be a text box below each question for them to explain.  Once submitted, the assigned FSO has an action item created for them called Process Post-Travel Debrief where the reporter's answers are presented to them to put into DISS.  Both the Post-Travel Debrief and Process Post-Travel Debrief have a default due date 5 business days from creation.  Here are the questions:
- Contact with foreign intelligence entities, or any foreign travel anomalies — unusual or suspicious occurrences of security or counterintelligence significance. 
- Deviations from the pre-submitted travel itinerary — any unplanned changes to destination, routing, or schedule. 
- Unplanned contacts with foreign governments, companies, or citizens during the trip, and the reason for that contact.
- Any foreign legal or customs incidents encountered during travel.
