# Visit Requests
## Feature Summary
This feature helps users submit visit requests and allows FSOs to process them. 

## Common
Upon reaching this page, all users will see a list of their submitted visit requests.  There will also be a button to lauch the "Submit a Visit Request" form.  There will also be a "Clone from previous request" option.  Users will often submit the same visit request to the same location on different dates.  Having the ability to prepopulate the form will allow the user to only modify dates. FSOs and Admins can mark the visit as processed or pending upon their review and submission in DISS. FSOs and Admins also have action items created for them when a requestor makes a visit request

Inputs:
    - Last Name:
    - First Name:
    - Email
    - Visit Start Date
    - Visit End Date
    - DISS SMO Code
    - Company or Orginization Name
    - Visit Address
    - Point of Contact Name
    - Point of Contact Email
    - Point of Contact Phone Number
    - High Level visit Desc. Note: Remind user not to input CUI or classified information into this.
    - Access Required: Pick from the following
        - Confidential 
        - Secret 
        - Top Secret
        - Top Secret/ SCI
    - Security POC Name
    - Security POC Email
    - Security POC Phone Number


## Non - IC Admin Panel
Non-IC users will also have the ability to view all reports in their purview and filter by suborganization.
