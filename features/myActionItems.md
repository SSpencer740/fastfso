# Action items
## Feature Description
Here is each user's personal action items that need to be completed, instead of tasks for others to do. 

## Common
All users of the platform will see their tasks in a summary in a tabular list when viewing this page.  They can filter on completion status, date range, and perform a keyword search.  When they click on a task, a detailed popup window will appear containing the details of the task.  It will contain a description including any web links, a due date field, a user input text box, and a place to upload files.  Here a LLM will be used to validate that the inputs the user provides, eg. cert of completion, reflect the requirement details outlined by the assigner. The asignee will have the opportunity to mark the task complete, triggering the LLM check.  Note: not all tasks will have a documentation output as proof. The assigner will check whether documentation is expected.  Once the asignee marks the task as complete, the assigner will have have a task created for them automatically to approve. 


## Auto action items
Non IC roles will also have tasks assigned to them. As defined in other .md files, users creating items in other features auto create tasks for any non IC and non read-only view.
