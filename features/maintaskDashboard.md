# Task Dashboard for users of fastFSO
## Feature Summary 
This dashboard provides a visual overview of task completion status.  The dashboard will appear the same for all user personas but the data displayed will vary based off of user data permission access. 

### Common 
A graphical representation of the work items they personally have to complete. Of the outstanding tasks left for the custom date range, some form of graph or pie chart will display the status of various items. 


### Non Individual Contributor Dashboard
Non-IC roles will also have a the same graphic and list available as described in Common, but will display the data for all of the people in the sub organizations in their perview.  This data must be also be able to be filtered by sub organization, group, and task type.  

### Individual contributor dashboard
ICs will have the name and contact info of their assigned FSO at the bottom of the dashboard.  There will be instructions prompting them to reach out to their assigned FSO if they have any questions or concerns.
