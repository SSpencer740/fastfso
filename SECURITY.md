# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, email **security@fastfso.com** with a description of the issue, steps to reproduce, and any relevant details. You should receive a response within a few business days.

Please give us a reasonable opportunity to investigate and address the issue before any public disclosure.

## Scope

This repository contains the fastFSO application source code. Reports about the code in this repository (authentication, tenant isolation, file handling, etc.) are in scope.
